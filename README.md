# Pranay Pazare — Portfolio

Personal portfolio site for **Pranay Pazare** — Blockchain & Full Stack Developer.

Built with Next.js 16 (App Router), React 19, Tailwind CSS v4, and shadcn/ui.

## Credit

This portfolio is based on the open-source [`chanhdai.com`](https://github.com/ncdai/chanhdai.com) template by **Nguyen Chanh Dai (@ncdai)**, released under the MIT License. Layout, components, and design system are derived from that project; personal content (bio, experience, projects, branding) is original to Pranay Pazare.

If you like the design, **star the original**: <https://github.com/ncdai/chanhdai.com>

## Local development

```bash
pnpm install
pnpm dev
```

Opens at <http://localhost:3000>.

## Deploy

The site is designed for Vercel. Import the GitHub repo at <https://vercel.com/new> — no environment variables required for the default build.
